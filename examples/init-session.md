# Example: `/init` 速写（12 题）

How imboss runs first-time person profile capture.

---

## Agent opens

> 我们先用 **12 题速写** 建你的个人画像（成长、履历感、审美与说话风格）。  
> 可随时说「跳过」。题号 1–4：

---

## Round 1

**1.** 怎么称呼你？  
**2.** 年龄段？`18–24` / `25–29` / `30–34` / `35–39` / `40–49` / `50+` / `不愿说`  
**3.** 性别或代词？（可跳过）+ 用「你」还是「您」？  
**4.** 一句话介绍自己（人，不是头衔列表）

### User (sample)

1. 阿现  
2. 30–34  
3. 女 · 你  
4. 从市场转创业，想靠 AI 把想法做成产品的人  

---

## Round 2

**5.** 哪段成长经历最塑造你？（一句）  
**6.** 学习背景：学历档 + 学科  
**7.** 工作背景：身份 + 行业 + 角色  
**8.** 最不想被怎样对待？（多选）说教 / 瞧不起不懂技术 / 空鸡汤 / 催逼 / 吓 / 敷衍 / 官腔 / 其他  

### User (sample)

5. 第一份销售工作被客户反复拒绝，后来靠听懂对方要什么翻盘  
6. 本科 · 市场营销  
7. 创业中 · 消费互联网 · 做过销售和运营负责人  
8. 说教、瞧不起不懂技术、空鸡汤  

---

## Round 3

**9.** 表达风格（1–3）：极简 / 正式商务 / 轻松朋友 / 锐利直接 / 温柔稳 / 幽默 / …  
**10.** 喜欢的颜色或视觉气质  
**11.** 电影/剧或书 1–3  
**12.** 压力下要：冷静清单 / 先稳住再方案 / 只要结论；幽默：不要 / 偶尔 / 可以多  

### User (sample)

9. 锐利直接、轻松朋友  
10. 黑白 + 一点电光蓝  
11. 《社交网络》、刘瑜的书  
12. 冷静清单；幽默偶尔  

---

## Read-back (imboss)

```markdown
# Profile · 阿现
- 30–34 · 你
- 销售出身转创业，靠 AI 做产品
- 塑造：销售一线被拒→学会听需求
- 教育：本科市场；工作：消费互联网 / 销售+运营 / 创业中
- 禁忌：说教、技术傲慢、鸡汤
- 风格：锐利直接 + 轻松朋友；黑白电光蓝
- 文化参照：社交网络、刘瑜
- 压力：冷静清单；幽默偶尔
```

**之后我这样对你说话（示例）：**

1. 「阿现，结论先说：现在别上 Redis，先看慢查询。原因三条，你拍板。」  
2. 不用「你不懂技术很正常哦～」这种俯就。  
3. 类比可以借「客户要什么」而不是「Kubernetes 编排」。  

> 要改哪几项？还是「先用着」？

## What changed vs no profile

| Without | With 阿现 |
|---------|-----------|
| 通用 founder 腔 | 销售隐喻 OK，学院黑话少 |
| 可能温柔说教 | 禁止俯就与鸡汤 |
| 中性审美 | 表达偏利落、短句 |
