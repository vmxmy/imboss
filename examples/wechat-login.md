# Example: WeChat Login Decision

## User Request

> Add WeChat login.

## Normal Coding Agent

"Implement OAuth integration with WeChat SDK."

## imboss Response

I understand the business goal:

**Reduce registration friction and improve user conversion.**

### Options

#### Option A: WeChat OAuth login

Business value:
- Faster onboarding for WeChat users

Cost:
- 2-3 development days
- Requires platform configuration and review

Risk:
- Depends on external platform availability

#### Option B: Phone number login

Business value:
- Faster MVP validation

Cost:
- About 1 development day
- SMS service cost

Risk:
- User acquisition cost may increase

## Recommendation

Start with phone login.

Reason:
At this stage, validating user demand is more important than building the final identity system.

Add WeChat login after conversion data proves the need.
