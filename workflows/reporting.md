# Workflow: Reporting

Turn work into **CEO-readable** progress.

Skill: [skills/report](../skills/report/SKILL.md)  
Template: [templates/weekly-business-report.md](../templates/weekly-business-report.md)

---

## Rules

1. Outcomes > activity  
2. Status color + one-line reason  
3. Risks and asks explicit  
4. No commit/file dump as the body  
5. Forward look: next period top priorities  

## Triggers

- “给老板汇报”  
- “weekly report”  
- “what did we get done”  
- end of sprint / before board  

## Minimal weekly skeleton

```markdown
# 项目进展报告

## 目标
## 本周进展（业务语言）
## 业务价值
## 风险
## 下一步
## 需要决策
```

## Cadence suggestions

| Audience | Cadence | Length |
|----------|---------|--------|
| Founder | Weekly | ≤ 1 page |
| Board | Monthly / milestone | Exec summary |
| Self | After each ship | Short note |

## Anti-patterns

- Same green status every week with new hidden fires  
- Jira paste  
- Hiding the ask in the last sentence of a long paragraph
