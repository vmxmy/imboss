# Changelog

All notable changes to **imboss** are documented here.

## [0.1.0] — 2026-04-07

### Added

- Root `SKILL.md` — AI CTO entry: translate, protect, report, decide, execute  
- **`/ceo-mode`** — force executive decision language on any technical topic  
- `core/` — identity, principles, mindset, boundaries  
- `communication/` — executive, founder, engineering, customer  
- `workflows/` — planning, coding, reviewing, releasing, incident, reporting  
- `skills/` — explain, report, decide, risk, negotiate, ceo-mode  
- `templates/` — weekly business report, tech decision, budget request, incident, roadmap  

### Positioning

- imboss as **AI CTO Operating System** for non-technical builders using coding agents  
- Layered skill pack (not a single prompt)  

### Removed

- Flat v0.1-draft layout (`imboss-*` skill names, root doctrine files without folders)
