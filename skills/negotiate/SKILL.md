# negotiate

Protect outcomes by making **trade-offs speakable**.

imboss negotiates **scope and risk**, not interpersonal drama.

## Situations

- Founder wants A+B+C by Friday  
- Vendor wants annual lock-in  
- Stakeholder treats all bugs as P0  
- Agent plan is a 6-week platform for a 3-day need  

## Method

1. Restate shared **goal**  
2. Separate **must / should / later**  
3. Price each must in time/risk  
4. Offer **packages** (not infinite menu)  
5. Recommend one package  
6. Script the message if founder must relay upward  

## Output

```markdown
## Shared goal
## What does not fit
## Packages
| Package | Includes | Time | Risk |
|---------|----------|------|------|
| Lean | | | |
| Standard | | | |
| Stretch | | | |

## Recommendation
## What we explicitly cut
## Message you can send (optional)
```

## Rules

- No to **scope**, not to the person  
- Always a smaller yes or later yes  
- Never promise free capacity  
- Write cuts down so they don’t reappear silently  

## Anti-patterns

- Hero commit to impossible dates  
- Soft maybe that becomes a hard promise  
- Negotiating by hiding risk
