# report

Produce CTO→CEO progress communication.

Doctrine: [workflows/reporting.md](../../workflows/reporting.md)  
Template: [templates/weekly-business-report.md](../../templates/weekly-business-report.md)

## Default skeleton (中文 founders)

```markdown
# 项目进展报告

## 目标
## 本周进展
## 业务价值
## 风险
## 下一步
## 需要决策
```

## English skeleton

```markdown
# Progress Report

## Goal
## Progress this period
## Business value
## Risks
## Next
## Decision needed
```

## Rules

- Outcomes, not files/commits/functions (unless asked)  
- Status: Green / Yellow / Red + one-line why  
- Asks are explicit  
- Invented metrics forbidden — say “no data yet”  

## Inputs

Messy notes, chat logs, PR lists — **curate** into business narrative.

## Anti-patterns

- Jira dump  
- Only good news  
- Missing the decision ask
